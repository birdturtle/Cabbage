This beta adds optional local RuneLite plugin loading for private testing. Cabbage 1.1.0 remains the stable release.

- Add plugin-only JARs under **Settings → Advanced → Developer plugins**. Enable the mode and launch your character normally; no IDE, Gradle, credential-file copying or Cabbage restart is required.
- RuneLite's official developer sideloader runs through Cabbage's managed Java, with signed runtime metadata and verified client downloads. Normal RuneLite remains available by switching developer mode off.
- On first developer launch, your existing RuneLite profiles, Hub plugin choices and supported plugin data are copied into a separate beta profile. Beta settings persist across JAR updates; the normal and beta copies do not synchronize. Account sessions, credentials and unrelated sideloaded code are not copied.
- Missing/changed JARs, declared client-version mismatches and invalid staging paths produce actionable errors. Failed launches can be retried without losing profile settings. Close RuneLite before changing the staged plugin set.
- Clarified settings timing and corrected clipped text in the log dropdown.

Local plugins are unreviewed code with access to the RuneLite client and its account session. Only add files from a developer you trust. Supply plugin-only JARs with their required dependencies; a bundled development client is not supported. WikiPane and other plugins are distributed separately.

The developer launch and profile behavior have been tested interactively on Linux. Windows packages are built/tested by CI; Windows gameplay and native file-picker acceptance still need beta testing.

Enable **Include beta updates** in Cabbage to receive this prerelease, or download the AppImage/EXE below. See [developer-plugin setup and compatibility notes](https://github.com/birdturtle/Cabbage/blob/v1.2.0-beta.2/docs/developer-plugins.md).

Beta 2 preserves signed runtime test fixtures byte-for-byte on Windows. The first beta tag did not publish downloadable packages because this test caught checkout line-ending changes. Runtime signature verification has not been relaxed.
