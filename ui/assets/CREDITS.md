# Launcher assets

`cabbage-source.png` is the RuneScape cabbage image supplied by the project owner. `launcher.png` and the native PNG/ICO files are exports of that image, with its transparency and proportions preserved. The image remains the property of Jagex Ltd.

`runescape-background.png` is the edited Lumbridge courtyard screenshot supplied by the HapticScape project owner. The inherited screenshot remains the property of Jagex Ltd. It is not covered by the code license. The launcher retains its Jagex imagery attribution.
